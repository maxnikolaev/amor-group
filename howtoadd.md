# Как подключить свой ПК к репозиторию AMOR Group

Эта инструкция — для сотрудников. Пройдите шаги по порядку. Если что-то не получается — пишите Максу (@hermes_fl).

---

## Что вам понадобится

1. **Аккаунт на GitHub**. Если нет — зарегистрируйтесь на [github.com](https://github.com) (бесплатно).
2. **Приглашение в репозиторий**. Попросите Макса добавить ваш GitHub-аккаунт в collaborators.
3. **Программа GitHub Desktop** — самая простая версия. Скачайте с [desktop.github.com](https://desktop.github.com/) и установите.

---

## Шаг 1. Установите GitHub Desktop

1. Откройте [desktop.github.com](https://desktop.github.com/) и нажмите **Download for Windows** (или Mac).
2. Запустите установщик, дождитесь окончания.
3. Откройте GitHub Desktop.

## Шаг 2. Войдите в GitHub

1. В GitHub Desktop нажмите **Sign in to GitHub.com**.
2. Введите логин и пароль от вашего GitHub-аккаунта.
3. Подтвердите вход.

## Шаг 3. Выберите папку на компьютере

1. GitHub Desktop спросит, где хранить проекты. Выберите удобное место, например:
   - `C:\Users\Имя\Documents\AMOR` (Windows)
   - `~/Documents/AMOR` (Mac)
2. Запомните эту папку — все файлы проектов будут внутри.

## Шаг 4. Склонируйте репозиторий

1. В GitHub Desktop нажмите **File → Clone repository**.
2. В списке найдите **amor-group** (если не видите — проверьте, что приняли приглашение от Макса).
3. Выберите путь (папка из шага 3) и нажмите **Clone**.

## Шаг 5. Откройте папку

После клонирования у вас на ПК появится папка `amor-group`. Внутри:

```
amor-group/
├── skills/          ← технические скиллы
├── methods/         ← методологии
├── cases/           ← проекты
├── howtoadd.md      ← этот файл
└── README.md
```

---

## Как добавлять файлы

### Простой способ (GitHub Desktop)

1. Скопируйте файл в нужную папку внутри `amor-group` на вашем ПК (например, в `cases/...`).
2. Откройте GitHub Desktop. Вы увидите ваш файл в списке слева.
3. В поле **Summary** (слева внизу) напишите коротко, что вы добавили. Например: «Добавил смету на А-60 кирпич».
4. Нажмите **Commit to main**.
5. Нажмите **Push origin** (сверху).

Всё! Файл улетел на GitHub. Через 5 минут сервер Hermes его увидит.

### Как получать обновления от других

Когда кто-то другой добавил файл:

1. Откройте GitHub Desktop.
2. Нажмите **Fetch origin** (сверху).
3. Если есть изменения — нажмите **Pull origin**.

Файлы коллег появятся в вашей папке.

---

## Важные правила

- ✅ **Добавляйте файлы** в правильную папку (skills, methods, cases).
- ✅ **Пишите понятные коммиты**: «Добавил смету А-60», а не «update».
- ❌ **Не удаляйте** чужие файлы. Если нужно убрать — переместите в `archive/`.
- ❌ **Не редактируйте** чужие файлы напрямую — создайте копию с версией.

---

## Если что-то не работает

1. **GitHub Desktop пишет «Authentication failed»** — выйдите и войдите заново: File → Options → Accounts → Sign out → Sign in.
2. **Не видите репозиторий** — проверьте, что приняли приглашение от Макса (проверьте почту, привязанную к GitHub).
3. **Конфликт** — не паникуйте. Напишите Максу (@hermes_fl), он разберётся.
