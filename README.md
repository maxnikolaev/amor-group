- **Фокус** — заряжать команду: 💰 кто сколько заработал, ⚖️ скандалы-суды, 🏗 масштаб (метры/высота/этажи), 👤 конкретные люди, 🤝 сделки. Только РФ (исключение — наши девелоперы за рубежом).
- **North Star** — внутренний ориентир (в пост НЕ выводится): выход на МОЭКС.
- **AI-маршрут** — `GPT-5.6 Sol` с reasoning `high`; при недоступности — `GLM-5.2`, затем `DeepSeek v4 Flash`.
- **Постинг** — production-скрипт `/home/max/PROJECTS/dev-market-news/post.py`; токены и API-ключи находятся только в `.env` с правами `600` и в git не коммитятся.

Утверждённый формат одного выпуска:

1. **Одна карусель** — по одной квадратной карточке `1600 × 1600` на каждую новость, в том же порядке, что и текст.
2. **Один полный текстовый пост** — заголовок `🏗 Рынок девелопмента · {дата}`, видимая нумерация новостей и ссылки, зашитые в фразу `По данным 🔗 Источника`. Отдельных строк с URL нет.
3. **Один отдельный MP3** — полная озвучка всего поста с названием файла по дате, например `18 августа`.

### Смысловые карточки

Карточка должна расширять новость визуальным фактом, а не просто украшать её:

- конкретный отель, ЖК, торговый центр или другой актив → точное реальное фото объекта;
- конкретная территория → карта, генплан, кадастровый контур или аэросъёмка;
- распределённые площадки → честная карта распределения, а не случайный участок;
- статистика → инфографика только по цифрам источника;
- регулирование → понятная схема механики и условий.

Формат — только статичные квадратные JPEG, преимущественно белый фон, шрифт Inter. Запрещены видео, клипарт, шаблонные городские панорамы, логотип вместо объекта и сгенерированные фотографии реальных объектов. Если одна картинка подходит для десяти несвязанных новостей, она считается слишком шаблонной. Полные правила хранятся на сервере в `dev-market-news/VISUAL_DESIGN.md`; для рендера установлен отдельный Pillow runtime и общие helpers `visual_tools.py`.

### Озвучка и отказоустойчивость

- Провайдер — **ElevenLabs**, модель `eleven_v3`, голос `FZGeNF7bE3syeQOynDKC`.
- TTS-скрипт начинается с `[not fast] [sexy]`; HTML и URL не произносятся, текст и нумерация соответствуют посту.
- Генерируется только один финальный вариант. Резервные аккаунты используются последовательно только при исчерпании кредитов предыдущего.
- Если ElevenLabs недоступен или кредиты закончились на всех аккаунтах, карусель и текст всё равно публикуются, а аудио молча пропускается.
- В Telegram никогда не отправляются сообщения вида «не удалось подключиться к модели», ошибки API или уведомления о закончившихся кредитах — они остаются только в локальных логах Hermes.

### Порядок публикации

Сначала полностью готовятся текст, все карточки и необязательное аудио. Только после проверки пакет отправляется подряд: карусель → текст → MP3. Скрипт проверяет лимит Telegram, квадратный формат карточек, соответствие их количества числу новостей и отсутствие видимых URL. Журнал `dev-market-news/runs/` хранит Telegram message IDs и блокирует повторную публикацию одного дня.

│       ├── материалы/           # документы, фото
│       │   └── research/        # исследования (рынок, аналоги, экономика)
│       ├── файлы проекта/       # финмодели, проекты домов
│       ├── from-tg-chat/        # файлы, присланные в Telegram-чат
│       ├── транскрибации/       # транскрипты разговоров (пишет бот)
│       └── log/                 # вехи, инциденты, корректировки модели
├── howtoadd.md      # как подключить свой ПК (инструкция для сотрудников)
└── README.md        # этот файл

### Ключевые файлы

- **`sync.md`** — единый источник правды по статусу проекта (что есть / блокеры / следующие шаги / цифры). Обновлять при каждом изменении. Шаблон — `methods/sync-file-template.md`.
- **`транскрибации/`** — только `.md`-файлы, имя `YYYY - MM DD - канал - участники - тема.md`. Каналы: `телефон`, `телеграм`, `встреча`, `зум`, `диктофон`, `Яндекс.Диск` и др.
- **`research/`** — исследования (рынок, нормативы, аналоги). **`log/`** — внутренние вехи, инциденты, корректировки.

## Как устроена работа

### Принцип хранения

| Где | Что хранится |
|-----|-------------|
| **GitHub (этот репо)** | Проекты, методология, транскрипты, документы — источник правды |
| **Сервер Hermes** | Технические файлы, секреты (`.env`, cookies), кэш, временные данные |

### Поток: транскрибация разговора

1. Кидаешь `@amorgroupteam_bot` голосовое / аудио / видео / ссылку (YouTube, Яндекс.Диск) с комментарием «проект, канал, участники, тема».
2. Бот скачивает → Deepgram → `.md`.
3. Сохраняет в `cases/<проект>/транскрибации/`, коммитит, присылает ссылку на GitHub.
4. Если проект не указан — спросит.

### Поток: файлы из Telegram-чата

1. Участник присылает файл в чат проекта.
2. Hermes сохраняет его в `cases/<проект>/from-tg-chat/` с именем `YYYY-MM-DD_HHmm_<кто>_<описание>.<ext>`.
3. Коммитит и пушит.

### Правила

- **`git pull` перед любой работой** — участники грузят файлы через GitHub Web напрямую, в обход сервера.
- **`sync.md`** — единый источник правды по проекту; обновлять при каждом изменении.
- **Секреты** (`.env`, cookies, ключи) — только на сервере, в git не коммитятся.
- **Транскрипты** — только `.md`, медиа/JSON в репозиторий не попадают.
- **Чужие файлы не удалять** — перемещать в `archive/`; не редактировать напрямую, создавать копию.
